cucumber - Fabric 1.21.4 client mod (needs Java 21 + Fabric API 0.119.2+1.21.4)
Build:  gradle build            (Gradle 8.12+ and JDK 21 installed)
Jar:    build/libs/cucumber-1.0.0.jar -> .minecraft/mods
Or push this folder to GitHub: the Actions tab builds the jar (artifact "cucumber-jar").
Key:    O opens/closes the menu (rebind in Controls > cucumber)
